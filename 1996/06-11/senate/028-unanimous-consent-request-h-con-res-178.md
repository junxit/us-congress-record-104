# UNANIMOUS-CONSENT REQUEST--H. CON. RES. 178

**Speaking:** Lott, Trent (L000447) [R-MS]

**Measures:** H.Con.Res. 178

```
              UNANIMOUS-CONSENT REQUEST--H. CON. RES. 178

  Mr. LOTT. Mr. President, I ask unanimous consent that debate now 
begin on the conference report to accompany the current budget 
resolution, House Concurrent Resolution 178, and that once the Senate 
receives the conference report, it be considered as having been read 
and all time consumed be considered used as part of the statutory 10-
hour time limit.
  The PRESIDING OFFICER. Is there objection? Without objection, it is 
so ordered.
  Mr. LOTT. Mr. President, I ask unanimous consent that request be 
vitiated. We need to get one final clearance on that.
  The PRESIDING OFFICER. Without objection, it is so ordered.

                          ____________________
```
