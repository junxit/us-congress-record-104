# PROGRAM

**Speaking:** Grassley, Chuck (G000386) [R-IA]

```
                                PROGRAM

  Mr. GRASSLEY. Mr. President, the leader would like me to inform all 
of our colleagues that there will be a period for morning business for 
2\1/2\ hours to accommodate a number of requests by Members. It is 
hoped that during tomorrow's session, the omnibus appropriations 
conference report will become available. Senators should therefore be
```
