# PRAYER

```
                                 PRAYER

  The Chaplain, Rev. James David Ford, D.D., offered the following 
prayer:
  Let us pray using the words of St. Francis:
  Lord, make us instruments of Your peace.
  Where there is hatred, let us sow love; where there is injury, 
pardon; where there is discord, union; where there is doubt, faith; 
where there is despair, hope; where there is darkness, light; where 
there is sadness, joy.
  Grant that we may not so much seek to be consoled as to console, to 
be understood as to understand, to be loved as to love. For it is in 
giving that we receive, it is in pardoning that we are pardoned, and it 
is in dying that we are born to eternal life.
  Amen.
```
