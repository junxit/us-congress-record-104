# ORDER FOR VOTE ON CLOTURE MOTION--H.R. 2127

**Speaking:** Dole, Robert J. (D000401) [R-KS]

**Measures:** H.R. 2127

```
              ORDER FOR VOTE ON CLOTURE MOTION--H.R. 2127

  Mr. DOLE. Mr. President, I now ask unanimous consent that 
notwithstanding the provisions of rule XXII, the vote on invoking
```
