# UNANIMOUS CONSENT REGARDING RULE XXII

**Speaking:** Dole, Robert J. (D000401) [R-KS]

```
                 UNANIMOUS CONSENT REGARDING RULE XXII

  Mr. DOLE. Mr. President, I ask unanimous consent that Saturday count 
as the intervening day necessary under rule XXII.
  The PRESIDING OFFICER. Is there objection? Without objection, it is 
so ordered.

Democratic leader, because that will save a pro forma session tomorrow.
```
